# 01 – Termékkoncepció

## 1. Egy mondatban

**Az ai2know.it az AI tudáselemek otthona és a learning curve-ök platformja:** itt él minden
prompt, skill, MCP, guardrail, eval, compliance guide, szerepkör, tutorial, videó és link; ezekből
oktatók és szervezők képzések, workshopok, események után **személyre szabott tanulási útvonalakat**
(learning curve) raknak össze, megosztják, a résztvevők végigmennek rajtuk, és az eredmény a
**skillpass.id** profilon látszik.

## 2. Szereplők

| Szereplő | Mit akar | Belépés |
|----------|----------|---------|
| Látogató (keresőből, közösségi linkből) | gyorsan megtalálni egy promptot, eszközt, magyarázatot | nem kell – teaser + nyilvános minta |
| Tag | a teljes tudástár, kedvencek, saját curve-ök, haladás | skillpass.id (ingyenes) |
| Oktató / szervező | workshop után curve-öt készíteni a résztvevőknek, látni a haladásukat és a visszajelzést | skillpass.id + curve-készítő jog |
| Résztvevő | megkapni a „mit nézzek meg utána" listát, végigmenni, igazolást kapni | skillpass.id |
| Szerkesztő (operátor) | elemeket felvinni, ellenőrizni, moderálni | aibos.space konzol (aibos-auth) |
| Partner rendszer (superskiller, aiagentek, aibootcamp) | ai2know elemekre hivatkozni, beágyazni; saját objektumait curve-be adni | M2M API |

## 3. Fő felhasználói utak

1. **Workshop utáni curve (a fő út):** az oktató a workshop végén „Új curve az eseményből" →
   kiválaszt 12 elemet (3 videó, 5 prompt, 2 skill, 1 guardrail, 1 superskiller lecke), mindegyikhez
   egy mondat „miért nézd meg" → láthatóság: *kohorsz* (a résztvevők meghívó kóddal / QR-ral) →
   közzétesz → a résztvevők a QR-t beolvasva belépnek skillpass-szal, felvételre kerülnek, haladnak →
   elvégzéskor visszajelzés → a skillpass profiljukon „Elvégezte: …" bejegyzés; az oktató profilján
   „Készítette: … – 34 elvégző, 4,7★".
2. **Keresőből érkező látogató:** Google-ből egy prompt teaser oldalára érkezik → látja a leírást,
   a prompt első sorait, a kapcsolódó curve-öket → „A teljes prompt belépés után" → skillpass
   regisztráció → visszakerül ugyanide, teljes tartalommal.
3. **Szerepkör használata:** „AI marketing asszisztens" szerepkör → benne 6 skill, 2 MCP, 3 guardrail,
   2 eval, 1 compliance guide → egyben letölthető/telepíthető csomag (belépve).
4. **Superskiller tanuló:** a superskiller leckében beágyazott ai2know prompt kártya → kattintásra a
   teljes elem (SSO, újabb belépés nélkül); a superskiller e-learning lépésként szerepel egy ai2know curve-ben.
5. **Saját curve tagként:** kedvencekből egy kattintással privát curve („Saját jegyzetem"), később
   megosztható.

## 4. Mi nem az ai2know.it

- Nem LMS (nincs óraterv, osztályzat, oktatói adminisztráció – az a superskiller).
- Nem közösségi háló (fórum, csoport, poszt a superskillerben él; az ai2know csak hivatkozik rájuk).
- Nem saját auth / profil (skillpass.id), nem saját admin UI (aibos.space).

## 5. Sikermérők (I. felvonás után 90 nappal)

| Mérőszám | Cél |
|----------|-----|
| Regisztráció a teaser kapukon (látogató → tag) | ≥ 4% konverzió |
| Közzétett learning curve | ≥ 30 (workshopokból) |
| Curve elvégzési arány (felvett → elvégzett) | ≥ 35% |
| Átlagos visszajelzés | ≥ 4,3 / 5 |
| „Nincs találat" keresések aránya | < 5% |
| Organikus keresési kattintás a teaser oldalakra | havi növekedés |
