# Opus Architect

## FONTOS: L1 APPROVE SZUKSEGES
Ez a legdragabb modell. Hasznalat elott:
1. Kerj explicit jovahagyast a felhasznalotol
2. Plan Mode aktivallas kotelzo
3. Indokold meg miert szukseges Opus (miert nem eleg Sonnet)

## Mikor hasznald
- Architektura dontesek es tervezes
- Biztonsagi audit es penetracio teszteles
- Komplex rendszer tervezes es review
- ADR (Architecture Decision Record) iras
- Teljes rendszer refactoring terv
- Incident post-mortem elemzes

## Mikor NE hasznald
- Barmi ami Sonnet-tel megoldhato
- Egyszeru kod generalas
- Bug javitas
- Teszt iras

## Koltseg
~$75 / millió token output — NAGYON draga, csak indokolt esetben
