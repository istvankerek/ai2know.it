# Admin Experience Direction

- Admin UI alap: shadcn/ui fehér felület, Tailwind semantic tokenek, lucide ikonok.
- Minden CRUD modul DLA: dashboard, list, add, detail, trash.
- Idegen kulcsot user nem gépelhet; relation combobox és create-in-modal kötelező.
- Minden mutáció soft delete/restore kompatibilis és auditált.
- Placeholder admin tilos: production adminnak használható listákat, formokat, statusokat és hibakezelést kell adnia.
